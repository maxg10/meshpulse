HOW TO INSTALL
Three Ways to Install
1

Browse in Mapper

Open Config → Plugins → Plugin Store tab. Browse and install with one click. Mapper handles the download.

2

Download & Upload

Download the .meshplugin file, then upload via Config → Plugins → Install Plugin.

3

Manual Install

Extract the ZIP to plugins/author/name/ in your mapper directory and restart.

🔧

Build Your Own Plugin

Plugins can add backend Python logic and frontend UI. They receive hooks for messages, positions, telemetry, and more. Full API available.
